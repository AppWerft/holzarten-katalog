A catalog for managing and displaying tree species, including botanical information, images, search and filtering.

== Description ==

Tree Species Catalog provides tools to manage and display a catalog of tree species in WordPress.

Features include:

* Manage tree species and their botanical information.
* Store and display images for individual species.
* Search and filter the catalog.
* Display active tree species in the frontend using a shortcode.
* Optional integration with WooCommerce for associating tree species with products.
* Manage the origin of wood using geographic coordinates.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/holzarten-katalog` directory, or install the plugin through the WordPress plugin screen.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Open the 'Holzarten' menu to manage the catalog.
4. Use the `[hk_holzarten]` shortcode to display the catalog on a page.

== Frequently Asked Questions ==

= Does this plugin require WooCommerce? =

No. The basic catalog functionality can be used without WooCommerce. WooCommerce-specific features are available when WooCommerce is installed and active.

= How can I display the catalog? =

Insert the `[hk_holzarten]` shortcode into a page or post.
